# 飞书产品描述与当前实现对照

对照来源：用户提供的《Agent ship kit》飞书文档截图（2026-11-03）。
这里核对本分支实际代码；桌面已接通、手工 CLI 可用和未来规划分别说明。

| 文档要求 | 当前覆盖 | 证据与缺口 |
| --- | --- | --- |
| 人只与船长沟通，A/B 需求可交替推进 | 已实现 | 同一船长对话可连续讨论不同目标，宿主执行结构化创建、转交、查询和回复；进度来自真实状态 |
| 船长识别任务归属，转交已有小队或新建小队 | 已实现 | 路由经宿主校验并原子落盘；在途补充增加 contextRevision，使旧工序结果失效并重新独立验证 |
| 不确定归属时主动反问 | 已实现 | 持久化 clarifying 状态、候选目标和另开新目标入口；重启不丢失，未澄清前不启动工人 |
| 下级问题逐级解决，船长解决不了才找人 | 已实现主要机制 | `askParents` 先复用决定，再让 lead/captain 各最多尝试两次；仍未解决才进入人工队列；必须人工处理的高风险动作保留人工门禁 |
| 单需求队长拥有全局视角，派工与返工，对结果负责 | 部分 | 每需求独立计划、分支和工件，队长参与分工、问题处理；工序推进与返工由宿主状态机执行；队长会话目前每轮新建，靠宿主传递上下文，并非常驻记忆会话 |
| 一个工人一个或多个工序，服从小队长安排 | 部分 | 工序可编辑，按工序配置角色/运行时/模型；目前每次工序调用新会话，不支持同一个有身份连续性的工人跨工序复用 |
| 开工读工序说明，按需查询团队手册 | 已实现 | 桌面配置必读 Markdown，64 KB 总注入预算与摘要回执；同一会话最多三次按需知识检索 |
| 积累可复用经验，沉淀并方便查询知识库 | 已实现 | 已验证交付提炼有来源的候选，人工独立审核后供后续工人召回；保留 CLI lesson 互通 |
| 密码本保存端到端测试账号与 key | 已实现 | OS 钥匙串保护，按授权注入指定验证进程；无明文查看入口，事件仅存引用，输出与证据脱敏 |

代码入口：`packages/orchestrator/src/orchestrator.ts`、
`packages/orchestrator/src/service.ts`、`apps/desktop/src/workspace.tsx`、
`packages/core/src/workflows.ts`、`cli/src/learning.ts`。
