# 多 Agent 派发应分别验证通知、现场与真实执行者

## Conclusion

通知管家成功、登记负责人现场与目标被独立 Agent 实际执行是不同事实，应分别反馈并验收。双目标测试应由产品自主启动独立负责人，再用成果中的执行环境身份与登记的 Pane 对照，防止把管家代做或测试预创建现场误当成分发成功。

## Evidence

隔离工作区中，桌面连续创建两个目标，真实管家启动 alpha-owner 与 beta-owner；各自产出 JSON 并实际检查，executorPane 与各自登记现场一致且不同于管家。未分配一分钟后先请管家核查，登记拒绝管家或其他活动目标现场。

## Applicability

Crewvane 的轻量 Herdr 分发、状态反馈与真实模型验收；不等价于第三方 CLI 的工具权限隔离。

## Uncertainty

Confirmed for local real-model trials; Stale Risk for models and CLI behavior
