# Crewvane 终端验收需核验真实副作用与异步结果

## Conclusion

对 Herdr 重绘式 TUI 的执行验收应使用真实 shell 文件副作用并检查渲染文本，不能仅匹配外层 PTY 连续字节；异步 IPC 状态需断言其完成值而非 Promise 本身。自定义 CLI 的长中文提示还需限制 canonical TTY 单行 UTF-8 字节数。

## Evidence

macOS arm64 打包应用中真实自定义 CLI 启动、argv、目标 stdin、重启复用和退出拒发通过；终端测试真实写出文件并通过隐藏恢复检查。Playwright 1.64.1 本地实现对 predicate() 返回的 Promise 先判 truthy，已用 expect.poll 替代。

## Applicability

Crewvane Electron/Herdr 集成测试及自定义交互式 CLI 通道；升级 Playwright、Herdr 或终端实现后需重新核验具体行为。

## Uncertainty

Confirmed in Crewvane v0.4.2 local macOS arm64 tests; Stale Risk for dependency behavior
