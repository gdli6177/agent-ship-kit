## 试用发现并修正的问题

- 继承共享 ignore 的 worktree，本地 setup 曾把已有标记误报为自身修改；现在检查前后
  文件是否一致，并按 AGENTS 是否 tracked 判断是否应排除它。
- 当前主机宽松 umask 曾使 launchd 拒绝 plist；现在显式设为 0600，真实 bootstrap
  与执行均通过，回归测试同时检查权限。
- 试用器最初未关闭 OMP stdin，已修正为显式结束输入；安装脚本也从固定快照运行，
  避免并行编辑源文件影响运行中的 shell 读偏移。
- OpenCode 路由返回模型不可用 / 凭据过期，未计作通过；没有修改凭据，换用已有的
  Magpie 路由完成试用。这不是对所有模型提供方可用性的保证。

## 复跑与边界

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm test:dogfood -- --model=provider/model
```

最后一条会真实调用模型并注册系统用户级定时任务，需使用本机有效的模型连接。
试用器结束时卸载定时器，临时项目、源码归档与 JSON 报告留在系统临时目录；
不会自动写入当前项目。原始模型输出不进入仓库。

Linux cron 的行为由自动测试覆盖，未进行真实 Linux 系统调度试用；全部宿主的 UI
技能发现也未逐一打开验证，实际核对的是隔离安装目录和 CLI 加载提示。
CLI / Git hook 不能拦截宿主全部文件工具调用；强制 pre-tool 检查仍需宿主接线。
