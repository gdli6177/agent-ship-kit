# Crewvane｜协航

**把所有事，交给一位管家。**

Crewvane 是一个本地桌面注意力中心。你在同一个工作区记录多个项目目标和个人事项，由唯一的 Herdr 管家统筹推进。注意力页只显示真正需要你决定、验收、跟进或介入的事情，不需要记住每个会话在做什么。

- 一个工作区一位全局管家，所有项目都找它。
- Herdr 提供持久 Session；安装包内置并管理已验证的 Herdr CLI，本机已安装的 CLI Agent 可直接使用。
- 人的原话、截图和 Agent 的具体答复按目标隔离保存；自由消息不会冒充进度、验收或批准。
- 负责人按需创建，在 Herdr 中执行并通过 `crewvane` 写回进展。
- 项目可配置三档上线策略，默认外部审批；决定账本避免同类问题反复询问。
- 高风险动作始终升级给人，自动上线策略也不能跳过。
- Herdr 的空闲或完成状态不等于成果完成，人工验收以交付摘要和真实检查记录为准。
- 需要你决定、验收、跟进或介入时，可把去重后的注意力事件推送到配置好的 HTTPS Webhook。
- Herdr 插件随应用自动安装，可在 Herdr 内查看注意力、一句话新建目标或直接回到全局管家。
- 插件通过 Herdr 原生事件即时同步负责人状态、现场移动与退出，桌面轮询只作断线兜底。
- 在 Herdr 管家终端直聊时，管家会通过 `crewvane direct` 把原话写回当前案卷或新目标；该命令只追加消息，不修改状态或下一步。未经写回的终端聊天不会进入 App。
- 桌面和 CLI 共用同一份锁保护的本地状态。
