# Crewvane｜协航

**把所有事，交给一位管家。**

Crewvane 是一个本地桌面注意力中心。你在同一个工作区记录多个项目目标和个人事项，由唯一的 Herdr 管家统筹推进。注意力页只显示真正需要你决定、验收、跟进或介入的事情，不需要记住每个会话在做什么。

- 一个工作区一位全局管家，所有项目都找它。
- Herdr 提供持久 Session；本机已安装的 CLI Agent 可直接使用。
- 工序只有步骤名称与提示词，创建目标时保存快照。
- 负责人按需创建，在 Herdr 中执行并通过 `crewvane` 写回进展。
- Herdr 的空闲或完成状态不等于成果完成，人工验收以交付摘要和真实检查记录为准。
- 桌面和 CLI 共用同一份锁保护的本地状态。

当前支持 macOS Apple Silicon。[下载安装包](https://github.com/gdli6177/crewvane/releases) · [使用说明](docs/crewvane.md) · [安装与发布](docs/releases.md)
