# Crewvane UI checklist

改完桌面 UI 后逐项勾选。任何一项失败都先修，不要用“看起来还行”代替。

## 改动范围

- [ ] 读了 `DESIGN.md` 与 `docs/design/brand-ui.md`。
- [ ] 新样式引用 token、语义 class 或 `apps/desktop/src/ui/` 原语。
- [ ] diff 中没有新增 hex / rgb / hsl / 字面字号 / 一次性阴影。
- [ ] 没有引入第二套组件库或第二套字体。
- [ ] 没有回退 0.5 的字号 scale、浅色对比度、单焦点环修复。

## 层级与文案

- [ ] 页面标题、区块标题、卡片标题、正文、元信息分别使用对应 `--fs-*`。
- [ ] 正文不是 `--muted`；说明与时间才是 `--muted`。
- [ ] 同一信息只说一次；标题、摘要、底部操作不重复同一句话。
- [ ] 中文文案克制、具体，没有玩梗或营销腔。
- [ ] 状态色没有单独承担语义，旁边有文字标签。

## 动作与布局

- [ ] 当前视区只有一个 `primary` 按钮。
- [ ] 表单提交用 `type="submit"`；取消/次要动作用 secondary 或 ghost。
- [ ] 按钮高度为 32（sm）或 36（md）；没有新的 34/37/38。
- [ ] 空态有标题 + 一句说明；有下一步时只给一个动作。
- [ ] 加载态写明正在做什么，不用大块骨架屏。
- [ ] 卡片内边距 16/20，区块间距 24/32，遵循 4pt。
- [ ] 设置项标题、说明、控件左对齐同一列；窄窗口单列。

## 键盘与主题

- [ ] Tab 到按钮、输入框、复选、开关时只有一圈可见焦点。
- [ ] 深色与浅色都检查：边框可见、正文对比度足够、状态柔底不刺眼。
- [ ] 弹窗关闭按钮有 `aria-label="关闭"`。
- [ ] 图标按钮都有可读标签。
- [ ] 空态、错误态、加载态在深色和浅色下都可读。

## 验证

- [ ] `pnpm typecheck`
- [ ] `pnpm test`
- [ ] `pnpm --dir apps/desktop exec vite build`
- [ ] macOS：`pnpm test:desktop`；Linux：注明跳过原因。
